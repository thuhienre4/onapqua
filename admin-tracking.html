Import transaction report (CSV)

Export the transactions report from your affiliate network and paste or upload it. Recognized columns: transaction/order ID, status, commission/payout, sale amount, currency, date, sub-ID/click ref (subId1, clickref, sid, afftrack), merchant. Rows are matched by network + transaction ID, so re-importing updates statuses instead of duplicating.

Settings

GA4 loads on the site only for visitors who accept analytics cookies. The API secret is used only by the server to send affiliate_conversion/affiliate_refund for confirmed transactions; it is never sent to browsers.

utm_campaign is set to product_review (or site) and utm_content to the CTA position. Off by default because some programs reject extra parameters — test a link after enabling.
